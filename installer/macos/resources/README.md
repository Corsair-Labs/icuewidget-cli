# CORSAIR macOS installer resources

These resources are used by `productbuild` to give the macOS installer package
a branded CORSAIR experience.

- `welcome.html`: installer welcome page copy and layout
- `readme.html`: installer readme page copy and layout
- `corsair-logo.png`: staged at build time from `installer/windows/assets/CORSAIRLogo2020_horiz_K.png`

The logo is intentionally sourced from the Windows installer assets so macOS and
Windows deliverables stay visually aligned.
