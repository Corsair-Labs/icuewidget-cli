iCUE Widget CLI

Create, validate, update, and package CORSAIR iCUE widgets from a native command-line tool.

  • icuewidget init MyWidget
  • icuewidget validate MyWidget
  • icuewidget update MyWidget --min-app-version 5.45
  • icuewidget package MyWidget

The installer also performs best-effort cleanup of older Python-distributed versions before installing the standalone Node CLI binary.
